# Installation Manual: Video Surveillance Server (MotionEye)

This document details the deployment of a local video surveillance system using Docker and MotionEye on Ubuntu Server. The system is designed to ingest video via RTSP protocol (e.g., Tapo C120 cameras), process motion detection in RAM to conserve disk IOPS, and maintain an automatic 7-day file rotation.

---

## 1. Environment Preparation

Ensure that the 1TB hard drive (connected to the motherboard via SATA) is properly mounted in the operating system. For this manual, we will assume that the mount point for videos is `/media/security/videos`.

### 1.1. Creating Directories
Create the necessary folder structure for configuration and storage:

```bash
# Directory for MotionEye configuration
sudo mkdir -p /opt/motioneye/conf

# Main directory for video storage (On your 1TB drive)
sudo mkdir -p /media/security/videos

# Directory for maintenance scripts
sudo mkdir -p /opt/scripts/security

```

---

## 2. Deploying the Container (Docker)

A temporary RAM volume (`tmpfs`) will be used so that MotionEye can process live video frames without overloading the read/write head of the mechanical hard drive.

### 2.1. `docker-compose.yml` file

Create the orchestration file in your preferred location (e.g., `/opt/motioneye/docker-compose.yml`):

```yaml
version: '3'
services:
motioneye:
image: ccrisan/motioneye:master-amd64
container_name: motioneye
restart: unless-stopped

ports:

- "8765:8765"

volumes:

# Time zone synchronization with the host

- /etc/localtime:/etc/localtime:ro

# Configuration persistence

- /opt/motioneye/conf:/etc/motioneye

# Video persistence (Points to the 1TB hard drive)

- /media/seguridad/videos:/var/lib/motioneye

tmpfs:

# Live video processing in RAM to protect the HDD

- /tmp:exec,mode=777

```

### 2.2. Starting the Service

Run the following command in the same directory where you saved the `docker-compose.yml` file:

```bash
sudo docker-compose up -d

```

The server will be accessible at: `http://<SERVER_IP>:8765`

---

## 3. Retention Automation (7-Day Cleanup)

To prevent the disk from filling up, the system will run an atomic script that removes old files and cleans the directory structure generated by MotionEye.

### 3.1. Cleanup Script

Create the file `/opt/scripts/seguridad/limpieza_rotativa.sh`:

```bash
sudo nano /opt/scripts/seguridad/limpieza_rotativa.sh

```

Paste the following code:

```bash
#!/bin/bash

# Path to storage on the hard drive
DIRECTORIO_VIDEOS="/media/seguridad/videos"

# 1. Delete files (.mp4, .jpg, .thumb) older than 7 days
find "$DIRECTORIO_VIDEOS" -type f \( -name "*.mp4" -o -name "*.jpg" -o -name "*.thumb" \) -mtime +7 -print -delete

# 2. Delete empty directories (folders with older dates)
find "$DIRECTORIO_VIDEOS" -type d -empty -delete

```

### 3.2. Execution Permissions

Grant the necessary permissions to the script:

```bash
sudo chmod +x /opt/scripts/seguridad/limpieza_rotativa.sh

```

### 3.3. Cron Scheduling

Add the task to the operating system scheduler so that it runs every day at 3:00 AM.


Open the root user's crontab:

```bash
sudo crontab -e

```

Add the following line to the end of the file:

```text
0 3 * * * /bin/bash /opt/scripts/seguridad/limpieza_rotativa.sh > /opt/scripts/seguridad/limpieza.log 2>&1

```

## 4. Web Interface Configuration (MotionEye)

Once the container is running, log in to the web interface as `admin` (no password by default) and make the following adjustments for each camera:

1. **Add Camera:**
* Type: `Network Camera`.

* URL (Example RTSP Tapo): `rtsp://username:password@<CAMERA_IP>:554/stream1`.

2. **Video Resolution & Framerate:**
* Adjust as needed; recommendation: 10 to 15 FPS to reduce CPU usage.

3. **File Storage:**
* Ensure the `Root Directory` is pointing to `/var/lib/motioneye` (which is internally mapped to your 1TB disk).

4. **Movies:**
* Enable option.

* `Movie Format`: **MP4** or **H.264/MP4**.

* `Recording Mode`: **Motion Triggered**.

5. **Motion Detection:**
* Enable option.

* Adjust `Frame Change Threshold`: Recommended between **3.5% and 5.0%** (calibrate according to the desired motion in the physical environment).
